# AdultMult TV

Простое приложение для Android TV 7.1.1+ с плиткой в FLauncher.
Открывает https://mult.adultmult.club/meepmeep.html через системный WebView.

## Сборка APK без Android Studio

1. Создайте **пустой публичный или приватный репозиторий** на GitHub.
2. Загрузите в него **содержимое** папки AdultMultTV (включая скрытую `.github/workflows/build.yml`). Проще всего распаковать ZIP на ПК, а затем через GitHub Add file → Upload files загрузить файлы с сохранением структуры. GitHub web UI может не принимать перетаскивание папки целиком; при необходимости используйте GitHub Desktop.
3. Откройте вкладку **Actions** → **Build AdultMult TV APK** → **Run workflow** (или дождитесь запуска при push).
4. После успешной сборки откройте запуск и скачайте артефакт **AdultMultTV-APK**.
5. Распакуйте ZIP артефакта, перенесите `app-debug.apk` на флешку, установите через X-plore.

Примечание: сборка не проверялась в этой среде (нет Android SDK). APK будет подписан отладочным ключом GitHub runner, поэтому при обновлении из другого запуска может понадобиться удалить предыдущую версию.
Если страница не работает в системном WebView 109, отдельное приложение не исправит проблемы сайта или сети.
